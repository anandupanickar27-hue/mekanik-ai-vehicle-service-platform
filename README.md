# Mekanik - AI Vehicle Service Platform

Mekanik is a vehicle service management platform that helps users manage vehicles, book service appointments, and receive assistance in identifying vehicle-related issues.

## Features

- User Authentication
- Vehicle Management
- Appointment Booking
- Dashboard Analytics
- AI-Assisted Issue Identification

## Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
